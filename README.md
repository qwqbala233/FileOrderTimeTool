# 批量文件排序/重命名工具（FileOrderTimeTool）

这是一个免安装的 Windows 桌面工具，用于可视化调整文件顺序、批量修改文件的修改日期或创建日期、批量重命名文件名和扩展名，并支持操作预览、冲突检测以及多级撤销和重做。

该工具的主要是通过修改文件的“修改日期”/“创建日期”数据，来达成“在资源管理器中选择 修改日期/创建日期 排序方式时，能显示出自己想要的文件排序”的效果，很利好我这种强迫症患者。至于能批量进行文件名和扩展名的修改，这纯粹是附赠的功能。
