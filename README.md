# 批量文件排序/重命名工具（FileOrderTimeTool）

这是一个免安装的 Windows 桌面工具，用于 Windows 的可视化文件排序、批量重命名和文件时间修改工具。

## 主要功能

- 🖱️ 拖拽文件，自定义排列顺序
- 🕒 批量修改文件的“修改时间 / 创建时间”
- ✏️ 批量重命名文件及扩展名
- 👀 修改前预览
- ⚠️ 冲突检测
- ↩️ 多级撤销 / 重做
