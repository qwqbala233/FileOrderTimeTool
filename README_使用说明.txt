批量文件排序/重命名工具 v1.8.4.4 测试版
============================

一、常见问题
------------
问：这个应用是用来做什么的？
答：本工具用于按照自定义排列顺序，批量更改文件的修改日期或创建日期，也可以批量修改文件名和扩展名。所有计划都可以先预览，实际文件更改在本次运行期间支持撤销和重做。

问：如何快速知道某个板块或设置的功能？
答：将鼠标悬停在该板块或设置上约 1 秒，即可查看功能说明。

问：“最晚日期”和“间隔”有什么作用？
答：程序先确定整组文件中最新的日期，再按间隔逐个向前计算其他文件的日期。例如最晚日期为 12:00、间隔为 30 秒、顺序为“最新→最旧”，前三个文件会得到 12:00、11:59:30、11:59:00。

问：“文件的最晚日期”读取哪一种日期？
答：在“修改模式：”中选择修改日期时，读取全部导入文件中最新的修改日期；选择创建日期时，读取最新的创建日期。

问：“当前时间”具体指什么？
答：它指点击“预览”或“应用更改”时电脑显示的本地时间。如果预览后过了一段时间才应用，程序会在应用时重新读取当前时间。

问：选择文件会影响哪些操作？
答：“更改文件日期”始终处理全部导入文件。文件名和扩展名重命名在有选择时只处理选中文件，没有选择时处理全部文件。

问：能否先看结果再真正写入？
答：可以。“预览”只显示计划结果，不会修改磁盘文件。


二、快速开始
------------
1. 从资源管理器把文件直接拖入主窗口。
2. 使用排序、移动或鼠标拖动，把文件排成需要的视觉顺序。
3. 选择要更改修改日期还是创建日期，设置最晚日期、间隔和日期顺序。
4. 如需改扩展名或文件名，勾选相应选项并填写内容。
5. 点击“预览”核对，再点击“应用更改”。

首次运行会自动打开使用说明。以后可点击右上角“？”或按 F1 查看。


三、导入、选择与查看
--------------------
- 只接受文件，文件夹会被忽略；重复文件只保留一份。
- 没有文件时显示“请直接拖入文件进行导入”。
- 文件名最多显示两行，悬停文件卡片可查看完整文件名。
- 单击选择一个；Ctrl+单击追加或取消；Shift+单击连续选择。
- 在空白处拖动可框选；Ctrl+A 全选；右键取消全部选择。
- Delete 只从工具列表移除选中文件，不删除磁盘文件。
- 双击图片会在工具内查看大图。左右方向键按当前视觉顺序切换图片。
- 双击视频或其他文件会用 Windows 默认程序打开。


四、排序与拖动
--------------
窗口宽度改变时会重新计算列数和间距，最后一行从第一列开始。

排序框只负责选择排序依据和升降序，不会持续限制文件顺序。选择后需要点击右侧“✓”执行一次排序；排序完成后，仍可继续拖动或使用移动按钮自定义排列。

点击“文件名 - 升序/降序”排序框可选择：
- 文件名、修改日期、创建日期、文件大小、文件类型。
- 分隔线下方的升序或降序。
- 左侧圆点分别表示当前依据和方向。

鼠标位于排序框时，滚轮切换排序依据，Ctrl+滚轮切换升降序。使用快捷键 Tab+↑/↓ 可直接切换排序依据，Ctrl+Tab+↑/↓ 可直接切换升降序。

没有选择时排序全部；有选择时，选中文件排序后会聚成一组并移到最前，未选文件保持原相对顺序。

第二排按钮依次为排序、移到最前、移到最后、移除、撤销和重做；右侧两个带文件标记的按钮是撤销更改和重做更改。鼠标悬停约 1 秒可查看名称和快捷键。

“移到最前”和“移到最后”把全部选中文件视为一个整体。拖动时蓝色插入线表示整组最终位置。


五、更改文件日期
----------------
“更改文件日期”始终处理全部导入文件。顶部“修改模式：”设置框用于选择要写入修改日期还是创建日期，并同时选择日期顺序。

最晚日期有三种来源：
1. 文件的最晚日期：读取当前所选日期类型的最新值。
2. 当前时间：在预览或应用时读取电脑的本地时间。
3. 自定义：显示具体日期和时间，点击日期区域可编辑；点击右侧下拉箭头可切换来源。

间隔支持秒或分。第一次启动默认使用“文件的最晚日期”；以后会记住上次选择的日期来源。每次启动时，自定义日期都会重新初始化为启动时的电脑本地时间。

“修改日期/创建日期 - 降序”时，第一个文件等于最晚日期，后续文件逐个变早；升序时，最后一个文件等于最晚日期。

鼠标悬停在修改模式设置框上时，普通滚轮切换修改日期/创建日期，Ctrl+滚轮切换升序/降序。日期来源和秒/分设置也可用普通滚轮循环切换。取消勾选“更改文件日期”后，顶部日期设置会变灰，悬停可查看启用提示。


六、更改扩展名
--------------------
勾选后输入 jpg 或 .jpg 均可。有选择时只处理选中项，没有选择时处理全部文件。此功能可与更改文件日期、批量重命名同时使用。


七、批量重命名
--------------
1. 勾选“批量重命名”，输入名称，例如“旅行照片01”。
2. 用鼠标框选纯数字“01”。
3. 点击“设置递增”。

框选“旅行照片1”中的“1”时，会生成旅行照片1至旅行照片9，然后生成旅行照片10、旅行照片11……。框选“旅行照片01”中的“01”时，会生成旅行照片01至旅行照片09，然后生成旅行照片10、旅行照片11……。原数字位数只是编号的最少位数，超过该位数时会自然增加，不会截断。未启用“更改扩展名”时保留原扩展名。

有选择时只改选中项，没有选择时修改全部。鼠标悬停在递增状态文字上可以查看当前框选内容、起始编号和最少位数。发现名称冲突时停止，不覆盖已有文件。


八、预览、应用与确认
--------------------
“预览”不会修改文件。表头会按当前模式显示“新修改日期”或“新创建日期”。预览窗口没有最小化按钮，关闭后焦点回到主窗口。

“应用更改”可以组合更改日期、扩展名和文件名。执行前会检查路径、两种文件日期、文件标识和目标名称；发现外部变化或冲突时停止。

所有二次确认窗口默认选中“确定”：Enter 或 S 确定，Esc 或 N 取消。


九、撤销与重做
--------------
“撤销/重做”只处理界面排列。“撤销更改/重做更改”处理已写入磁盘的文件名、扩展名、修改日期或创建日期，并在本次运行期间保留多级记录。

执行新的磁盘更改会清空磁盘重做记录。如果文件在程序外被移动、改名或更改日期，安全检查会停止撤销或重做。


十、默认快捷键
--------------
Delete                 移除选中
Enter                  排序
Ctrl+Z                 撤销界面操作
Ctrl+Shift+Z           重做界面操作
Shift+Enter            应用更改
Alt+Enter              预览
Ctrl+Alt+Z             撤销磁盘更改
Ctrl+Shift+Alt+Z       重做磁盘更改
← / →                  整组选中文件向前/后移动
↑ / ↓                  移到最前/最后
Tab+↑ / ↓              切换排序依据，不执行排序
Ctrl+Tab+↑ / ↓         切换升序/降序，不执行排序
F1                     打开使用说明

所有快捷键可在“快捷键设置”中查看、自定义、检查冲突或恢复默认。输入框获得焦点时，普通编辑键优先用于输入；下拉选择完成后，焦点会回到文件区。


十一、窗口与运行方式
--------------------
- 同一位 Windows 用户只能运行一个本工具实例。
- 重复启动时会恢复并唤回已有窗口。
- 程序记住上一次的窗口大小和最大化状态，不记住窗口位置。


十二、从源码生成 EXE
--------------------
把 FileOrderTimeTool.cs、Build_EXE.bat 和 app.manifest 放在同一文件夹，双击 Build_EXE.bat。

程序不需要 Python、Node.js、FFmpeg 或 Visual Studio，编译使用 Windows 自带的 .NET Framework C# 编译器。


十三、使用建议
--------------
批量写入前先用“预览”核对视觉顺序、文件名、扩展名和日期。处理重要文件或大量文件时，建议另外保留备份。
